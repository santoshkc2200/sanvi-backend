# Product Access API

Generated by `scripts/api-docs.sh`; edit Rust annotations and regenerate.

Examples: en-US / USD and ja-JP / JPY. Integer minor units: USD 1299 = $12.99; JPY 1200 = ¥1,200 (zero decimals).

## GET /api/v1/tenant/ecommerce/{tail}

Operation: `proxy_ecommerce_get`

Read through to ecommerce-service: `GET /api/v1/tenant/ecommerce/{tail}`
becomes `GET /v1/{tail}`, e.g. `stores` or `stores/123/products`.

Responses: 200, 400, 403, 502, 503

| Parameter | Location | Required | Type / bounds / default |
| --- | --- | --- | --- |
| `tail` | path | yes | type="string" |

## POST /api/v1/tenant/ecommerce/{tail}

Operation: `proxy_ecommerce_post`

Write through to ecommerce-service: `POST /api/v1/tenant/ecommerce/{tail}`
becomes `POST /v1/{tail}`. `Idempotency-Key` is forwarded; the service
requires it on every create.

Responses: 200, 400, 403, 502, 503

| Parameter | Location | Required | Type / bounds / default |
| --- | --- | --- | --- |
| `tail` | path | yes | type="string" |
| `Idempotency-Key` | header | yes | type="string" |
